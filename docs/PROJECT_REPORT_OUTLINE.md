# Project report outline

## Title
Cloud-Based Intrusion Detection and Security Event Monitoring System

## Problem statement
Small applications often need a simple way to collect and inspect suspicious web request events. This project demonstrates a basic centralized dashboard and transparent rule-based event classification.

## Objectives
- Accept security events from a form or CSV file.
- Analyze events using simple detection rules.
- Classify events by severity.
- Present events in a dashboard.
- Demonstrate containerization and a cloud VM deployment path.

## Modules
1. Event collection
2. Detection engine
3. Severity classification
4. Dashboard and reporting
5. Deployment

## Testing
Use the included sample CSV and demo-data button. Verify that suspicious patterns are marked MEDIUM or HIGH and ordinary requests remain LOW.

## Future scope
Cloud-managed database, CloudWatch integration, notifications, authentication, anomaly detection, and multi-user access.
